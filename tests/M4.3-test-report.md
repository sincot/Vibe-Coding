# M4.3 题目与做题页面 — 测试报告

范围：M4.3「题目与做题页面」——左侧题面/样例/限制/本人状态、CodeMirror 接入与降级、
语言切换与 `Ctrl+Enter`、提交快照与状态、逐测试点结果与 WA/编译诊断展示。改动包含
前端（`web/js/editor.js`、`web/js/pages/problem.js`、`web/js/judge.js`、
`web/js/lifecycle.js`、`web/css/styles.css`、`web/index.html`）与后端最小补充
（`ProblemStore::viewer_solved` + 详情 `solved`；提交响应新增 `output_truncated`、
`global_deadline_hit`、`cancelled`，非 AC 点 `actual_output` 始终返回）。

本轮在初版测试基础上补全：真实浏览器验证（含真实 CDN CodeMirror 高亮、窄视口布局、
ResizeObserver/refresh、编辑器释放）、前端 V8 覆盖率采集、编译阶段全局硬上限专项用例。

- 真实浏览器（可选工具）：`@playwright/cli` 0.1.21 + 真实 Chromium（`~/.cache/ms-playwright/chromium-1246`），

## 七、未验证项与边界

- 覆盖率来自 M4.3 页面级测试单轮，不代表全前端或全分支覆盖；未采集后端覆盖率。
- 真实浏览器验证在服务器本机无头 Chromium 执行，未覆盖 Windows 有头浏览器；窄屏为
  视口模拟，未做真机验证。M4.1 的浏览器脚本本轮未重跑（其结论不受本次改动影响）。
- 真实 CodeMirror 仅在 Chromium 内核验证，未覆盖 Firefox/WebKit 等其它内核。
- 判题相关破坏性场景（真实 TLE/MLE/fork 等）沿用 M3 既有隔离测试，未在本轮重复执行。
- 前端交互的提交在真实浏览器中沿用 jsdom 覆盖（本轮浏览器重点验证渲染/布局/编辑器），
  未在真实浏览器内跑完整真实判题提交。
