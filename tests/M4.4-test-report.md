## 4. 失败项定位与修复记录

### 4.1 集成 T-214：损坏 `per_case` 详情（测试缺陷）

- 用例：`M44-2 test_detail` 的「损坏 per_case 详情仍 200」等 5 项。
- 涉及函数：`submission_detail_json`（src/http/server.cpp:404）、`handle_submission_detail`（:1440）。
- 触发输入：`corrupt` 用户的 `per_case="not-json{"` 与 `"{\"a\":1}"`。
- 预期 / 实际：预期 200，实际 404。
- 分类：**测试缺陷**。根因：测试用 `alice.token` 请求 `corrupt` 用户的提交，接口按
  「非本人且非管理员」正确返回 404；实现无缺陷。
- 修复：改用归属用户 `corrupt.token`（`tests/integration/test_m44_history_api.cpp`）。
- 复测：`oj_m44_history_api_test` 复跑 90/90 通过（`/tmp/opencode/m44_api2.log`）。

### 4.2 前端运行脚本 `run_m44.sh`：`UID` 只读变量（脚本缺陷）

- 现象：`line 77: UID: readonly variable`，预置提交未写入，DOM 测试因历史为空报错。
- 分类：**测试脚本缺陷（环境/工具）**。根因：bash 中 `UID` 为只读内建变量，赋值失败，
  SQL 使用错误 user_id 触发外键失败。
- 修复：改用 `USER_ID`/`PROBLEM_ID`，并在预置后校验 `COUNT(*)=24`，失败即显式报错。
- 复测：`run_m44.sh` 复跑 31/31 通过。

### 4.3 M4.1 DOM：旧的「不提供提交历史空白入口」断言（已确认需求变更）

- 用例：`tests/frontend/m41_infrastructure_dom.mjs` M41-7。
- 预期 / 实际：旧断言要求导航不含「提交历史」，M4.4 依 SPEC UI-01/M4.4 要求接入该入口，
  实际包含 → 断言失败。
- 分类：**需求变更**（非回归、非实现缺陷）。依据 SPEC.md M4.4「在现有 hash 路由中加入
  本人提交历史和提交详情页，并接入导航」。
- 修复：将断言更新为「登录后显示已实现的提交历史入口」且 `href=#/submissions`；
  排行榜仍未实现，保留「不提供排行榜空白入口」断言。
- 复测：`run_m41.sh` 53/53 通过。

### 4.4 DOM F2/F7：测试等待条件与判定范围（测试缺陷）

- F2：翻页后立即读取行数，可能读到上一页残留 DOM。修复：等待行数等于目标值。
- F7：断言全页文本不含「提交历史」，但上一错误页按钮文案即「返回提交历史」。修复：改为
  仅判定 `#site-nav` 文本。
- 复测：`m44_history_dom.mjs` 31/31 通过。
