3. **公开样例是否参与判题**：SPEC 未明确，当前实现将全部 `testcases` 参与判题（M5.2 已记录），
   本轮未改动业务规则。
4. **Cron**：`scripts/backup.sh` 的 cron 说明与最小环境调用此前已验证；本轮**未安装**真实
   cron 任务（按要求）。
5. **性能**：仅测教学目标规模（≤5 并发）；队列满载按已确认规则返回有界 `503`，未要求超容量
   请求全部成功判题，未对并发时序做穷举。
6. **Windows 通道为可选补充**：`run_m64_browser.ps1` 的 Windows 运行需用户执行；服务器端
   有头已由 `run_m64_browser_headed_xvfb.sh` 完成，跨平台 Windows 结果回传不阻塞判定。
